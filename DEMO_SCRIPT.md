# Three-minute demo script

1. Introduce the problem: financial assistants often sound certain even when evidence is incomplete.
2. Open the live simulation and ask for the BTC consensus price.
3. Show the timestamp, independent source values, median, source count and spread.
4. Ask for the BTC market regime.
5. Highlight the deliberate refusal: a point-in-time snapshot cannot establish a regime.
6. Briefly show the serverless source and the two-source minimum.
7. Close with the product-feedback point: a simulated Alexa+ route makes prototype evaluation accessible without a consumer device, while transparent provenance should be a first-class agent pattern.
